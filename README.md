# 🎵 Song-of-Songs

> 雅歌。Song of Songs YouTube 頻道自動化項目

## 目標

利用 AI 自動化詩歌影片的製作與發布流程，讓人類專注於創意決策。

## 頻道資料

- **YouTube**: https://youtube.com/@-songofsongs
- **類型**: 基督教詩歌/敬拜歌曲 (粵語)
- **風格**: 歌詞影片為主，30秒 - 8分鐘短片

## 自動化流程

```
🎤 你錄音 → 🎵 AI 編曲 → 🎚️ AI Tuning → 🎬 AI 歌詞影片 → 📺 AI 發布 YouTube
```

## 自動化程度

| 環節 | 可行性 |
|------|--------|
| 歌詞影片製作 | 90-95% |
| 音樂編曲 | 70% |
| 人聲 Tuning | 80% |
