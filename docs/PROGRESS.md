# 進度追蹤

## 歌曲：永活的神

### 製作流程（更新版）

```
1️⃣ 錄音 → 2️⃣ Whisper 語音識別 → 3️⃣ 樂譜 OCR 確認 → 4️⃣ 時間軸對齊 → 5️⃣ 歌詞影片 → 6️⃣ 插畫整合 → 7️⃣ YouTube
```

#### Step 1：錄音
- 輸入：人聲錄音（.m4a）
- 工具：手機/電腦錄音軟件

#### Step 2：Whisper 語音識別
- 輸入：錄音 .m4a
- 工具：`brew install openai-whisper` + `whisper audio.m4a --model medium`
- 輸出：帶時間軸的原始歌詞
- 注意：粵語辨識可能有偏差，需校對

#### Step 3：樂譜 OCR 確認
- 輸入：樂譜圖片（.jpg/.png）
- 工具：AI 視覺辨識（如 Gemini、GPT-4o）
- 輸出：文字版歌詞
- 用處：確認 Whisper 辨識的歌詞是否正確

#### Step 4：時間軸對齊
- 輸入：Whisper 時間軸 + OCR 歌詞
- 工具：LRC 編輯器或手動調整
- 輸出：正確的 .lrc 歌詞檔案

#### Step 5：歌詞影片生成
- 輸入：音頻 + LRC 歌詞
- 工具：師弟開發的 `generate_video.py`
- 輸出：MP4 歌詞影片

#### Step 6：插畫整合
- 輸入：詩歌插畫（4張，16:9）
- 工具：Gemini 教育版 / 其他 AI 繪圖工具
- 輸出：整合插畫背景的 MP4

#### Step 7：YouTube 上傳
- 工具：YouTube API 或手動上傳
